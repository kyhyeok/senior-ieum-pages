# senior-ieum-pages

시니어이음 앱의 **홈페이지(앱 소개)와 법적 고지 정적 페이지**입니다. GitHub Pages로 `https://senior-ieum.co.kr` 에 게시합니다.

| 경로 | 무엇 | 스타일 |
|---|---|---|
| `/` | 홈페이지 — 앱 소개 | `home.css` |
| `/privacy/` | 개인정보처리방침 | `style.css` |
| `/location-terms/` | 위치기반서비스 이용약관 | `style.css` |
| `/account-deletion/` | 계정 삭제 요청 안내 | `style.css` |

- 🔴 **`main`에 push하면 곧바로 실제 사이트가 바뀐다**(Pages source = `main` `/`). 작업은 브랜치에서 하고, 로컬에서 열어 본 뒤(예: `python3 -m http.server`) 올린다 — Pages에는 브랜치 미리보기 배포가 없다.
- 🔴 `style.css`는 법적 고지 세 쪽 전용이다. 홈페이지 모양은 `home.css`에서만 바꾼다 — `style.css`를 고치면 고지 세 쪽 모양이 같이 바뀐다.

## 홈페이지(`/`)

- 담는 것은 **앱 소개만** — 스토어 링크 · 법적 고지 링크 · 문의·사업자 표기는 넣지 않는다(사용자 결정 2026-10-05 「지금은 앱 소개만 합니다」).
- 기능 문구는 **앱 원문에서만** 가져온다(`seniorhub-app` 화면 문구). 지어낸 기능을 적지 않고, 출처를 커밋 메시지에 적는다.
- 화면 사진(`assets/screens/`)은 **앱 골든(테스트 픽스처)만** 쓴다 — 실제 회원 정보가 찍힌 캡처는 쓰지 않는다. 어느 골든을 어떻게 잘랐는지는 커밋 메시지에 있다(`8a8c6c6` · 거기 적힌 `records.png`는 `35d0f7e`에서 뺐다).
- 「내 주변」 지도는 앱 화면이 아니라 **직접 그린 SVG 그림**이다(골든은 지도 바탕이 비어 있다). 그림 안에는 글자를 두지 않는다 — 좁은 폭·큰 글자 설정에서 겹치거나 잘린다.
- 시니어 기준: 가장 작은 글자 18px · 글자 대비 7:1 이상(라이트·다크 둘 다) · 얇은 굵기와 움직임 없음.
- 아이콘은 앱과 같은 lucide 그림(`lucide-static` v1.39.0)이다. 저작권·허가 고지 원문: [`licenses/lucide-static-1.39.0-LICENSE.txt`](licenses/lucide-static-1.39.0-LICENSE.txt)(ISC · 글자 크기 `type` 아이콘은 Feather 유래 MIT).

## 법적 고지 — 지금은 이 리포 게시본이 가장 새롭다

- **위치약관은 게시본이 정본이다.** 앱 약관 화면은 이 HTML을 기계로 옮긴 것이다(앱 `lib/core/location/location_terms_screen.dart` 머리 주석). 앱 화면과 게시본이 갈리면 §19① 동의 증빙이 갈리므로, 위치약관을 고치면 앱 화면도 같이 고치고 아래 대조를 돌린다.
- 앱 리포 `docs/2026-08-02-스토어-등록-서식/01-개인정보처리방침.md` · `04-위치기반서비스-이용약관.md`는 **처음 초안**이다. 2026-08-31 뒤로 바뀌지 않았고, 그 사이 게시본만 고쳐졌다(`b3e0b0b` 09-03 「관광지」→「가볼 곳」 · `f98ca7b` 09-15 상호·법정 기재사항). 그래서 md에는 「관광지」와 채우지 않은 자리(`{{ }}`)가 남아 있다 ⇒ **md에서 베껴 오지 않는다.**
- 개인정보처리방침·계정 삭제 안내의 정본을 어느 쪽으로 정했는지는 기록을 찾지 못했다 [미확인] — 지금은 게시본이 md보다 새롭다는 사실만 적는다.

⚠️ 알려진 어긋남: 고지 세 쪽 맨 위 「← 시니어이음 고지 모음」(`href="../"`)은 이제 고지 목차가 아니라 홈페이지로 간다. 링크 **글자**를 고치려면, 앱 `test/core/location/location_terms_published_test.dart`가 위치약관의 이 머리글을 글자째 단정하므로(`href`는 보지 않는다) **앱 테스트를 먼저** 바꾸고 이 리포를 고친다 — 사용자 결정 2026-10-05 「셋 다 그대로 둔다」 · `seniorhub-plan/docs/빚.md`.

## 게시 전 반드시 확인

1. `class="blank"` 로 노란 배경이 칠해진 자리가 **하나도 남아 있으면 안 된다.**

   ```sh
   grep -rn --include='*.html' 'class="blank"' . && echo "🔴 빈칸이 남았다 — 게시하면 안 된다"
   ```

   `--include='*.html'`을 빼면 이 README 자신이 걸려 늘 🔴가 뜬다.

2. 위치약관을 건드렸으면 앱 쪽 대조를 돌린다 — 앱이 위치약관 화면을 게시본과 글자까지 맞춰 본다. 대조는 **위치약관 한 쪽만** 본다(방침·계정 삭제는 대조가 없다).

   ```sh
   # seniorhub-app 리포에서
   tool/check_published_terms.sh          # 나란히 놓인 이 리포 사본으로(게시 전)
   tool/check_published_terms.sh --live   # 실제 주소로(게시 뒤)
   ```

   `--live`는 push하고 **10분쯤 지나** 돌린다 — 사이트 응답이 `cache-control: max-age=600`이라 바로 돌리면 캐시된 옛 판과 대조할 수 있다.

## 왜 앱·웹 리포가 아니라 별도 리포인가

- `seniorhub-web` 은 PRIVATE 이라 GitHub Pages 무료 플랜에서 안 된다
- `seniorhub-web` 에는 **배포 파이프라인이 없다**(`ci.yml` 에 배포 스텝 0건) — 라우트를 붙이면 파이프라인 신설까지 붙는다
- 방침·약관은 **코드가 아니라 문서**다. 빌드가 필요 없다
