## 게시 전 반드시 확인

`class="blank"` 로 노란 배경이 칠해진 자리가 **하나도 남아 있으면 안 된다.**

```sh
grep -rn 'class="blank"' . && echo "🔴 빈칸이 남았다 — 게시하면 안 된다"
```

## 왜 앱·웹 리포가 아니라 별도 리포인가

- `seniorhub-web` 은 PRIVATE 이라 GitHub Pages 무료 플랜에서 안 된다
- `seniorhub-web` 에는 **배포 파이프라인이 없다**(`ci.yml` 에 배포 스텝 0건) — 라우트를 붙이면 파이프라인 신설까지 붙는다
- 방침·약관은 **코드가 아니라 문서**다. 빌드가 필요 없다
